# EmerFlow
HopHacks 2026: AI agents that help hospitals manage patients during a crisis.

## Repo Structure

| Directory | What it is |
| --- | --- |
| [`capacity-map/`](capacity-map/) | Public site for civilians and EMS: live hospital capacity map, closest hospitals, emergency news, and a what-if incident simulator |
| [`agent-workflow/`](agent-workflow/) | Live view of the agent swarm deciding where patients go, plus the SimPy simulation server both parts use |
| [`data-gen/`](data-gen/) | Synthetic hospital operations and patient records for building and testing |

Each directory has its own README with setup and details.
